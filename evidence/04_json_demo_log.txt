  Output: {"name": "Alice", "age": 30}
  🔧 JSON đã được sửa thành công

[Markdown fences] 🔧 Fixed (on_fail=FIX)
  Input:  ```json
{"name": "Bob"}
```
  Output: {
  "name": "Bob"
}
  🔧 JSON đã được sửa thành công

[Single quotes] 🔧 Fixed (on_fail=FIX)
  Input:  {'name': 'Charlie', 'score': 95}
  Output: {
  "name": "Charlie",
  "score": 95
}
  🔧 JSON đã được sửa thành công

[Trailing comma] 🔧 Fixed (on_fail=FIX)
  Input:  {"key": "value",}
  Output: {
  "key": "value"
}
  🔧 JSON đã được sửa thành công

[Combined errors] 🔧 Fixed (on_fail=FIX)
  Input:  ```json
{'items': [1, 2, 3,], 'ok': true,}

  "items": [
    1,
    2,
    3
  ],
  "ok": true
}
  ❌ Không thể sửa JSON (Expecting value) → trả về JSON dự phòng
